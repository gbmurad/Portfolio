Tools I build for Claude Code, Anthropic's coding assistant. Each one is free: read the code, download it, or install it with one command.

The details

How a Skill Works

  1. Install it. One command copies the skill into Claude Code's skills folder, so it works in every project. A ZIP download works too.
  2. Ask in plain words. Each skill names the requests it answers, so Claude knows when to use it.
  3. Claude follows the steps. The skill's SKILL.md holds the steps, what done means and the guardrails. Its scripts handle what Claude cannot do alone, like asking macOS for permission.

A Claude Code skill that writes a short summary of each day you worked into its own Apple Calendar, so you can look back and see what happened on any date.

Ask "log today to my calendar" and Claude drafts a title and a few sentences for the day, shows you, and on your yes adds it as an all day event in a separate calendar called Workday Log. It can also backfill past days from your git history.

What you need

  • A Mac on macOS 14 or newer
  • Xcode Command Line Tools (xcode-select --install)
  • Claude Code

Safety

  • Events go only into the "Workday Log" calendar. Your own calendars are never touched.
  • Claude shows you every event before writing it.
  • Running it twice does not duplicate events.
  • To remove everything, delete the "Workday Log" calendar in the Calendar app.
  • The calendar syncs to iCloud, so the skill tells Claude to leave out secrets and private details.

Setup

install.sh asks a few quick questions (press Enter to keep the default). If you skip them, Claude asks on first use. Rerun sh ~/.claude/skills/day-to-calendar/scripts/setup.sh any time to change them.

Why it ships its own tiny app

# day-to-calendar: one calendar event per worked day

**Done =** each requested day has one all day event in the configured calendar, and the tool's output line confirms how many were added.

## Procedure
0. Settings live in `~/.config/day-to-calendar/config.json`. If that file is missing, run setup first: ask the user these six things (offer the default in brackets), then write the file with the keys shown, or tell them they can run `sh scripts/setup.sh` themselves.
   - Calendar name ["Workday Log"] → `calendar`
   - Color [teal]: red, orange, yellow, green, teal, blue, purple, pink, brown, gray, or a hex → `color`
   - Event length [all day] or a number of minutes → `all_day` (true/false), `duration_minutes`, and `start_time` like "17:00" if timed
   - Longest title [8 words] → `title_max_words`
   - Longest note [4 sentences] → `notes_max_sentences`
   Read the file on every run and obey the length limits when drafting.
1. Pick the days. Default is today. For a backfill, ask which dates, or use the days that have git commits or session history.
2. Gather what happened per day. Use, in this order: the current conversation, `git log --since="<date> 00:00" --until="<date> 23:59" --oneline` in the working repo, and any notes the user points to. Do not invent work you cannot see.
3. Write one event per day: a title within `title_max_words` (default 8) naming the main outcome, and notes within `notes_max_sentences` (default 4) in plain language on what was done, decided, and left open.
4. Leave out secrets, keys, passwords, balances, and private details of other people. The calendar syncs to iCloud.
5. Show the user the events and wait for a yes. The calendar is theirs.
6. Save them as `/tmp/day-events.json` in this shape:
   `[{"date":"2026-09-24","title":"Shipped the login fix","notes":"..."}]`
7. Check access: `sh scripts/daycal.sh status`. If it says `notDetermined`, run `sh scripts/daycal.sh request` and tell the user to click Allow in the macOS dialog. If it says `denied`, point them to System Settings, Privacy and Security, Calendars.
8. Write: `sh scripts/daycal.sh add /tmp/day-events.json`. Report the output line as printed.

## Guardrails
- Events go only into the dedicated calendar (the `calendar` setting, default "Workday Log"). Never touch the user's other calendars.
- Running twice is safe: an event with the same title on the same day is skipped.
- To undo everything, the user deletes that one calendar in the Calendar app.
- The first run compiles the helper and needs Xcode Command Line Tools (`xcode-select --install`). macOS 14 or newer.

// daycal.swift: writes one all day event per worked day into a dedicated Apple Calendar, through EventKit.
//   daycal status              -> the calendar access macOS has granted
//   daycal request             -> asks macOS for full calendar access (click Allow once)
//   daycal add <events.json>   -> writes the events, skipping any with the same title on the same day
// events.json: [{"date": "2026-09-24", "title": "...", "notes": "..."}]
// Everything goes into one calendar (default name "Workday Log"), so you can
// hide or delete it in one go and it never mixes with your own events.
import EventKit
import Foundation

let store = EKEventStore()
let args = CommandLine.arguments

// Settings live in ~/.config/day-to-calendar/config.json (written by setup.sh); DAYCAL_* env vars override.
let cfgPath = NSHomeDirectory() + "/.config/day-to-calendar/config.json"
let cfg = (FileManager.default.contents(atPath: cfgPath).flatMap { try? JSONSerialization.jsonObject(with: $0) as? [String: Any] }) ?? [:]
let env = ProcessInfo.processInfo.environment
let calendarName = env["DAYCAL_CALENDAR"] ?? (cfg["calendar"] as? String) ?? "Workday Log"
let colorSetting = env["DAYCAL_COLOR"] ?? (cfg["color"] as? String) ?? "teal"
let allDay = (cfg["all_day"] as? Bool) ?? true
let startTime = (cfg["start_time"] as? String) ?? "17:00"      // used when all_day is false
let minutes = (cfg["duration_minutes"] as? Int) ?? 60          // used when all_day is false

func parseColor(_ s: String) -> CGColor {
    let named: [String: String] = ["red": "E5484D", "orange": "F76B15", "yellow": "F5C400", "green": "30A46C",
        "teal": "21A08C", "blue": "0090FF", "purple": "8E4EC6", "pink": "E93D82", "brown": "A18072", "gray": "8B8D98"]
    var hex = (named[s.lowercased()] ?? s).replacingOccurrences(of: "#", with: "")
    if hex.count != 6 { hex = "21A08C" }
    let v = UInt32(hex, radix: 16) ?? 0x21A08C
    return CGColor(red: CGFloat((v >> 16) & 255) / 255, green: CGFloat((v >> 8) & 255) / 255, blue: CGFloat(v & 255) / 255, alpha: 1)
}

func statusWord() -> String {
    switch EKEventStore.authorizationStatus(for: .event) {
    case .notDetermined: return "notDetermined"
    case .restricted: return "restricted"
    case .denied: return "denied"
    case .fullAccess: return "fullAccess"
    case .writeOnly: return "writeOnly"
    case .authorized: return "authorized"
    @unknown default: return "unknown"
    }
}

func workCalendar() -> EKCalendar? {
    if let found = store.calendars(for: .event).first(where: { $0.title == calendarName }) {
        let want = parseColor(colorSetting)
        if found.cgColor != want && found.allowsContentModifications { found.cgColor = want; try? store.saveCalendar(found, commit: true) }
        return found
    }
    let cal = EKCalendar(for: .event, eventStore: store)
    cal.title = calendarName
    cal.cgColor = parseColor(colorSetting)
    let sources = store.sources
    cal.source = sources.first(where: { $0.sourceType == .calDAV && $0.title.lowercased().contains("icloud") })
        ?? store.defaultCalendarForNewEvents?.source
        ?? sources.first(where: { $0.sourceType == .local })
    do { try store.saveCalendar(cal, commit: true); return cal } catch { print("could not make the \(calendarName) calendar: \(error)"); return nil }
}

let cmd = args.count > 1 ? args[1] : "status"
if cmd == "status" {
    print(statusWord())
} else if cmd == "request" {
    let sem = DispatchSemaphore(value: 0)
    store.requestFullAccessToEvents { granted, error in
        print(granted ? "granted" : "not granted \(String(describing: error))")
        sem.signal()
    }
    _ = sem.wait(timeout: .now() + 900)
} else if cmd == "add" {
    guard args.count > 2, let data = FileManager.default.contents(atPath: args[2]),
          let list = try? JSONSerialization.jsonObject(with: data) as? [[String: String]] else {
        print("usage: add <events.json>"); exit(1)
    }
    guard let cal = workCalendar() else { exit(1) }
    let fmt = DateFormatter(); fmt.dateFormat = "yyyy-MM-dd"; fmt.timeZone = TimeZone.current
    var added = 0, skipped = 0
    for e in list {
        guard let day = fmt.date(from: e["date"] ?? ""), let title = e["title"] else { continue }
        let end = Calendar.current.date(byAdding: .day, value: 1, to: day)!
        let existing = store.events(matching: store.predicateForEvents(withStart: day, end: end, calendars: [cal]))
        if existing.contains(where: { $0.title == title }) { skipped += 1; continue }
        let ev = EKEvent(eventStore: store)
        ev.calendar = cal
        ev.title = title
        ev.notes = e["notes"]
        if allDay {
            ev.isAllDay = true
            ev.startDate = day
            ev.endDate = day
        } else {
            let hm = startTime.split(separator: ":").compactMap { Int($0) }
            let start = Calendar.current.date(bySettingHour: hm.first ?? 17, minute: hm.count > 1 ? hm[1] : 0, second: 0, of: day) ?? day
            ev.startDate = start
            ev.endDate = start.addingTimeInterval(TimeInterval(minutes * 60))
        }
        do { try store.save(ev, span: .thisEvent, commit: false); added += 1 } catch { print("failed \(e["date"] ?? ""): \(error)") }
    }
    do { try store.commit() } catch { print("commit failed: \(error)") }
    print("added \(added), already there \(skipped), calendar \(cal.title) on \(cal.source?.title ?? "?")")
} else {
    print("unknown command \(cmd); use status, request or add <events.json>"); exit(1)
}

Put a decision on trial and get a ruling you can act on.

Gavel is a Claude Code skill that turns a hard question ("should we rebuild the app?", "should I take this deal?", "should the store offer free shipping?") into a structured trial. A defense argues for it. A prosecution argues against it and has to name a better plan. A jury of 3 to 8 specialists, each with a different lens, votes alone without seeing the others. Then a judge, who wrote down his own view before hearing a word, weighs the evidence and rules.

You get one of five verdicts (Adopt, Adopt with conditions, Redesign, Reject, Insufficient evidence), the reasons, the strongest dissent, and the one fact that would flip the ruling.

you: use gavel for this: should we move the store to a subscription model?

Why a trial

Ask one chatbot whether your idea is good and it tends to agree with you. Ask a panel of them to discuss it and they tend to agree with each other: research on debates between language models finds they drop correct answers just to reach consensus. Neither gives you what a hard decision needs, which is the strongest case on both sides, judged by someone who is not trying to please anyone.

A courtroom is an old answer to that problem. Gavel keeps the parts of it that are backed by research and drops the theater. Every rule below exists because a study found that groups, juries or panels of models go wrong without it (see Why each rule exists).

What happens when you run it

 Setup         you pick the question, how hard the prosecution pushes, the jury, and each role's model
   │
 Filing        the clerk writes the case file: facts with sources, constraints, stakes
   │
 Pretrial      the judge sharpens the question, lists competing explanations, sets the criteria and
   │           the standard of proof, seats the jury, and seals his own first opinion
   │
 Openings      defense and prosecution write their cases at the same time, blind to each other
   │
 Rebuttals     each answers the other's strongest points (skipped in a quick trial)
   │
 Record        a script assembles the record, checks word limits, and puts the sides in random order
   │
 Jury          every juror reads the record and votes alone, in parallel, never seeing another ballot
   │
 Tally         a script checks every ballot and computes the vote, the spread and the minority report
   │
 Ruling        the judge returns fresh, opens his sealed opinion, weighs the evidence, and rules

Each role is a separate Claude subagent with a clean memory, so nobody can be swayed by what they were not supposed to see. The main conversation acts as the clerk: it runs the setup, passes files between roles, and reports the ruling, but it never argues, votes or edits anything a role wrote.

The courtroom, role by role

### The judge There is one judge, and he sits twice: once before the trial and once to rule. Only the second sitting decides, so two judges can never disagree. Each sitting is a fresh subagent on the model you chose (Opus by default, because the ruling is the product); research found a judge brought in fresh at the end resists the biases that build up over a long debate better than one who sat through every round.

Pretrial. Before any argument, the judge reads only the case file and: 1. Sharpens your question into one testable motion ("Resolved: the store should move to a subscription model"). 2. Writes 3 to 5 competing explanations of what is true, including the motion, a rival plan or doing nothing, and one nobody has raised yet. 3. Sets 2 to 4 weighted criteria the decision should turn on (cost, risk, customer value, and so on). 4. Seats the jury: your chosen seats, or the specialists this case needs, each with its own question. 5. Sets the standard of proof (below). 6. Writes a sealed prior: his honest opinion and a probability, before hearing anyone. Nobody else reads it.

Ruling. The judge comes back with a fresh memory, opens his own sealed prior, reads the record and the jury's ballots, and rules. He must show how far the trial moved him from his first opinion. He may overrule the jury, but only by explaining why in writing, and the jury's vote is printed under his ruling either way.

### The defense Argues for the motion in at most 500 words, then a 250 word rebuttal. Every claim is numbered (F1, F2) and tagged with its support: [case] with a quote from the case file, [source] with a named source, or [assumption] said plainly. Jurors give unsupported claims no weight.

### The prosecution Argues against the motion under the same limits and tagging (claims A1, A2). The prosecution is not allowed to just pick holes. It has to name the rival it would choose instead (another plan, or doing nothing) and lay out the most likely way the motion fails, step by step. You choose how hard it pushes:

LevelWhat it does
FairBuilds the strongest honest case against and concedes openly what the defense will get right
ToughPresses hard on the real weak points and concedes nothing the record does not prove
RuthlessAssumes the motion fails and shows exactly how, attacking every claim it rests on

At every level an attack without support counts for nothing with the jury. Ruthless means rigor, not rudeness.

### The jury 3 to 8 jurors, each a separate subagent. Every juror reads the record and nothing else, then works in a fixed order: facts first, vote last. 1. Up to six findings, each tied to a claim id, graded verified, plausible or assumption, and marked for or against the motion. 2. A score from 1 to 5 on each of the judge's criteria. 3. Only then a vote: the verdict, a probability from 0 to 100 that adopting the motion is right, and a confidence level. 4. The decisive point, what would change their mind, and any conditions.

Jurors may also object that the question itself is badly framed.

### Deliberation (optional) With --deliberate, jurors get one look at the other ballots, shown as Juror A, B, C in random order, and may revise once. Anyone who changes their verdict, or moves more than 15 points, must name the new point that moved them. If most changes name nothing new, or everyone simply drifts toward the majority, the script throws the second round out and the judge gets the blind vote instead.

The verdict

VerdictMeans
AdoptDo it as stated
Adopt with conditionsDo it, provided the listed conditions are met
RedesignThe goal is right, the plan is not; rework it
RejectDo not do it; the rival plan or doing nothing is better
Insufficient evidenceThe record cannot support a decision yet; here is what to find out

Standard of proof. The burden is always on the defense: the idea has to earn its adoption. The judge sets the bar by how hard the decision is to undo. Cheap to reverse: *more likely than not*. Costly or hard to undo: *clear and convincing*.

The ruling file always has the same sections: the verdict line, the ruling in plain words, how far the judge moved from his sealed prior, the decisive evidence, the strongest dissent stated fairly, conditions, the one fact that would flip the ruling, two or three things to watch, and the vote.

Limits, honestly

  • Every juror is a Claude model, so they share blind spots. Mixing models helps a little; it does not make

them independent. The ruling says how varied the jury was.

  • No study has tested a full courtroom like this one. Each rule is grounded in research; the whole is a design.
  • Nothing makes a judge immune to a persuasive argument. Word limits, random order, a sealed prior and graded

evidence reduce the known biases; they do not remove them.

  • For a question with a right answer (a bug, a fact, a calculation), a trial is the wrong tool. Gavel says so.

# gavel: put a decision on trial, get a ruling you can act on

**Done =** `ruling.md` exists in the case folder, `gavel.py close` accepted it, and the user has the verdict, the
dissent, and the one fact that would flip it.

You are the **clerk**. You run the setup, file the case, call each role as a fresh subagent on the model the
setup names, run the script between stages, and report the ruling. You never argue, vote, judge, or edit
anything a role wrote. Role briefs: `references/roles.md`. Juror bench: `references/bench.md`. Why each rule
exists: `references/research.md`. `<skill>` below is this skill's folder (printed when the skill loads).

## Procedure
1. **Is this a trial?** If the question has a checkable answer (a fact, a bug, a sum, a test that would settle
   it), say so and answer it directly; a vote does as well as a debate there. Otherwise tell the user the cost
   once (2 judge runs, 2 to 4 speeches, one run per juror) and go to setup.
2. **Setup.** If the user says "use my last settings" or passes `--last`, run `gavel.py settings`, show the line,
   and skip to step 3 with `--last`. Otherwise:
   - **The question.** If they have not given it, ask them to type it in one sentence.
   - **First menu** (one AskUserQuestion call, four questions):
     - "How hard should the prosecution push?" Fair (concedes what is true) · Tough (Recommended) · Ruthless
       (attacks every claim, concedes nothing unproven)
     - "Who sits on the jury?" The judge picks 5 for this case (Recommended) · I'll choose the seats · Quick
       trial: 3 seats, no rebuttals
     - "Model for the judge?" Opus (Recommended) · Fable · Sonnet · Same as this chat
     - "Default model for the jury?" Sonnet (Recommended) · Haiku (cheapest) · Opus · Fable
   - **Second menu** (one call): "Model for the defense?" and "Model for the prosecution?" (Sonnet
     (Recommended) · Opus · Fable · Haiku). If they chose to pick seats, add two multiSelect questions from the
     bench: "Build and money seats" (engineer, finance, operations, security and privacy) and "People and market
     seats" (designer, customer, competitor, legal and compliance). Tell them they can type anyone under Other,
     such as "a retired airline pilot", and give one seat its own model as "designer: opus". The premortem
     seat always sits. 3 to 8 seats in all.
   - "Same as this chat" is `inherit`: spawn that role without a model.
3. **File the case.** Run `python3 <skill>/scripts/gavel.py new "<question>"` with the choices as flags:
   `--opposition`, `--judge`, `--defense`, `--prosecution`, `--jury`, `--seats "a, b: opus"` or `--quick`, plus
   `--deliberate`, `--research`, `--last` when asked. It prints the case folder and the plan; show the plan line.
   A FIX line means a choice was invalid: ask again. Fill `case.md`: facts with sources, constraints, what has
   been tried, stakes. Ask at most two questions, only for a fact the case turns on. Never invent facts.
4. **Pretrial.** Spawn the judge with brief 1 on the judge's model. `{N}` is the setup's `jurors`. Run
   `gavel.py pretrial <case>`; it prints each seat's ballot file and model. On a FIX line, send it to the judge
   once and rerun.
5. **Openings.** In one message, spawn the defense (brief 2) and the prosecution (brief 3, with the level
   paragraph for the setup's `opposition` in place of `{LEVEL}`) in parallel, each on its model.
6. **Rebuttals** (not in a quick trial). In one message, spawn both rebuttals (brief 4) in parallel.
7. **Record.** `gavel.py record <case>`. A speech over its word limit goes back to its side once.
8. **Jury.** In one message, spawn every seat with brief 5, in parallel, each on the model `gavel.py pretrial`
   printed for it. Add the premortem paragraph only to the premortem seat. Then `gavel.py tally <case>`; send
   any FIX line to that juror once.
9. **Deliberation** (only with `--deliberate`, or offered when the tally says `split` and the stakes are high).
   Spawn every juror again with brief 6, then rerun the tally. Round 2 counts only if the jurors who moved name
   a new point; otherwise the script falls back to the blind vote.
10. **Ruling.** Spawn a fresh judge with brief 7 on the judge's model. Run `gavel.py close <case>`; a FIX line
    goes back to the judge once.
11. **Report** in at most eight lines: the VERDICT line, the ruling in plain words, the vote (counts, median,
    spread), the strongest dissent, what would flip it, and the path to `ruling.md`. Quote; never soften.

## Guardrails
- Each role reads only the files its brief names and writes only its own file. Roles return one line.
- The sealed prior is read by the judge alone. The clerk never paraphrases a speech to another role.
- Never more than two rounds of argument. Never show jurors each other's ballots before their blind vote.
- The prosecution's level changes how hard it pushes, never its duty to name a rival and support every claim.
- The ruling stands as written. To challenge it, file a new case with the new facts.
- Case files can hold private facts. Keep `.gavel/` out of version control.
- Jurors on one model share blind spots. The tally says how varied the jury was; repeat that when it matters.

#!/usr/bin/env python3
"""gavel.py: the parts of a Gavel case that should never be left to judgment. Standard library only.

    python3 gavel.py new "<motion>" [setup flags]  open a case folder with its setup; print the path and the plan
    python3 gavel.py settings [--dir DIR]          the setup saved from the last case (for "use my last settings")
    python3 gavel.py pretrial CASE                 check the judge's pretrial.json against the setup
    python3 gavel.py record CASE [--seed N]       assemble record.md for the jury (checks word limits)
    python3 gavel.py tally CASE [--seed N]        check every ballot, write tally.json and jury-packet.md
    python3 gavel.py close CASE                   check ruling.md and add a line to the docket
    python3 gavel.py list [--dir DIR]             past cases and their verdicts

Exit codes: 0 ok, 1 the case needs a fix (each problem is printed on its own line), 2 bad usage.
"""

VERDICTS = ["adopt", "adopt_with_conditions", "redesign", "reject", "insufficient"]
LABELS = {"adopt": "Adopt", "adopt_with_conditions": "Adopt with conditions", "redesign": "Redesign",
          "reject": "Reject", "insufficient": "Insufficient evidence"}
SIDE = {"adopt": "for", "adopt_with_conditions": "for", "redesign": "against", "reject": "against",
        "insufficient": "neither"}
CONFIDENCE = {"low": 0.5, "medium": 1.0, "high": 1.5}
GRADES = {"verified", "plausible", "assumption"}
FAVORS = {"for", "against", "neither"}
STANDARDS = {"preponderance", "clear_and_convincing"}
CAPS = {"opening-for.md": 500, "opening-against.md": 500, "rebuttal-for.md": 250, "rebuttal-against.md": 250}
SLACK = 1.10  # a speech may run 10% over its cap before the record refuses it
MOVE = 15     # probability points a juror may drift in round 2 without giving a reason
RULING_SECTIONS = ["## Ruling", "## From my prior", "## Decisive evidence", "## Dissent", "## Conditions",
                   "## What would flip this", "## What to watch", "## The vote"]
MODELS = ("opus", "fable", "sonnet", "haiku", "inherit")  # what the Agent tool accepts; inherit = this chat's model
LEVELS = ("fair", "tough", "ruthless")                   # how hard the prosecution pushes
ROLES = ("judge", "defense", "prosecution", "jury")
DEFAULT_SETUP = {"opposition": "tough", "jurors": 5, "seats": None, "quick": False, "deliberate": False,
                 "research": False,
                 "models": {"judge": "opus", "defense": "sonnet", "prosecution": "sonnet", "jury": "sonnet"}}


class CaseError(Exception):
    """A problem in the case files that a role must fix. Carries every problem found, not just the first."""

    def __init__(self, problems):
        self.problems = problems if isinstance(problems, list) else [problems]
        super().__init__("; ".join(self.problems))


# ---------- helpers ----------

def slug(text, limit=48):
    s = re.sub(r"[^a-z0-9]+", "-", text.lower()).strip("-")
    if len(s) > limit:
        s = s[:limit + 1]
        s = s[:s.rfind("-")] if "-" in s else s[:limit]  # cut at a word boundary, never mid word
    return s or "case"


def words(text):
    return len(re.findall(r"\S+", text))


def read(path):
    with open(path, encoding="utf-8") as f:
        return f.read()


def write(path, text):
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w", encoding="utf-8") as f:
        f.write(text)


def load_json(path):
    try:
        return json.loads(read(path))
    except FileNotFoundError:
        raise CaseError(f"{os.path.basename(path)}: missing")
    except json.JSONDecodeError as e:
        raise CaseError(f"{os.path.basename(path)}: not valid JSON ({e.msg}, line {e.lineno})")


def seat_file(seat):
    return slug(seat, 32) + ".json"


# ---------- setup ----------

def parse_seats(text):
    """'engineer, designer: opus, a retired airline pilot' -> [{'seat': ..., 'model': ...}]; premortem always seated."""
    seats = []
    for item in (t.strip() for t in text.split(",")):
        if not item:
            continue
        name, model = item, None
        if ":" in item:
            head, tail = item.rsplit(":", 1)
            if tail.strip().lower() in MODELS:
                name, model = head.strip(), tail.strip().lower()
        seat = {"seat": name}
        if model:
            seat["model"] = model
        seats.append(seat)
    if not any(s["seat"].lower() == "premortem" for s in seats):
        seats.append({"seat": "premortem"})
    return seats


def build_setup(motion, saved=None, **choices):
    """Merge defaults, the saved settings and this case's choices; check every value; return the setup."""
    setup = json.loads(json.dumps(DEFAULT_SETUP))
    for layer in (saved or {}, {k: v for k, v in choices.items() if v is not None}):
        for key, value in layer.items():
            if key == "models":
                setup["models"].update({r: m for r, m in value.items() if m})
            elif key in setup:
                setup[key] = value
    setup["motion"] = motion.strip()
    if setup["quick"] and not setup["seats"]:
        setup["jurors"] = 3
    bad = []
    if not setup["motion"]:
        bad.append("setup: the question is empty")
    if setup["opposition"] not in LEVELS:
        bad.append(f"setup: opposition must be one of {list(LEVELS)}")
    for role in ROLES:
        if setup["models"].get(role) not in MODELS:
            bad.append(f"setup: model for {role} must be one of {list(MODELS)}")
    if setup["seats"]:
        names = [s["seat"] for s in setup["seats"]]
        if not 3 <= len(names) <= 8:
            bad.append(f"setup: the jury needs 3 to 8 seats including the premortem, got {len(names)}")
        if len({seat_file(n) for n in names}) != len(names):
            bad.append("setup: two seats share a name")
        bad += [f"setup: model for seat {s['seat']} must be one of {list(MODELS)}"
                for s in setup["seats"] if s.get("model", "sonnet") not in MODELS]
        setup["jurors"] = len(names)
    elif not isinstance(setup["jurors"], int) or not 3 <= setup["jurors"] <= 8:
        bad.append("setup: jurors must be a whole number from 3 to 8")
    if bad:
        raise CaseError(bad)
    return setup


def load_setup(case):
    path = os.path.join(case, "setup.json")
    return load_json(path) if os.path.exists(path) else None


def seat_model(setup, seat):
    for s in (setup or {}).get("seats") or []:
        if s["seat"].lower() == seat.lower() and s.get("model"):
            return s["model"]
    return (setup or DEFAULT_SETUP)["models"]["jury"]


def open_case(base, setup):
    day = datetime.date.today().isoformat()
    case = os.path.join(base, f"{day}-{slug(setup['motion'])}")
    k = 2
    while os.path.exists(case):
        case = os.path.join(base, f"{day}-{slug(setup['motion'])}-{k}")
        k += 1
    os.makedirs(os.path.join(case, "ballots", "round1"))
    write(os.path.join(case, "setup.json"), json.dumps(setup, indent=2) + "\n")
    write(os.path.join(case, "case.md"),
          f"# Case\n\n**Motion.** {setup['motion']}\n\n## Facts\n\n## Constraints\n\n## Stakes\n")
    remembered = {k: v for k, v in setup.items() if k != "motion"}
    write(os.path.join(base, "settings.json"), json.dumps(remembered, indent=2) + "\n")
    return case


def describe(setup):
    m = setup["models"]
    jury = (", ".join(f"{s['seat']} ({seat_model(setup, s['seat'])})" for s in setup["seats"])
            if setup["seats"] else f"{setup['jurors']} seats picked by the judge ({m['jury']})")
    flags = [f for f in ("quick", "deliberate", "research") if setup.get(f)]
    return (f"judge {m['judge']} · defense {m['defense']} · prosecution {m['prosecution']} "
            f"({setup['opposition']}) · jury: {jury}" + (f" · {', '.join(flags)}" if flags else ""))

def check_pretrial(case):
    p = load_json(os.path.join(case, "pretrial.json"))
    setup = load_setup(case)
    bad = []
    if not str(p.get("motion", "")).strip():
        bad.append("pretrial.json: motion is empty")
    if p.get("standard") not in STANDARDS:
        bad.append(f"pretrial.json: standard must be one of {sorted(STANDARDS)}")
    hyps = p.get("hypotheses", [])
    if not isinstance(hyps, list) or not 3 <= len(hyps) <= 5:
        bad.append("pretrial.json: hypotheses must be a list of 3 to 5")
    elif not all(isinstance(h, dict) and h.get("id") and str(h.get("text", "")).strip() for h in hyps):
        bad.append("pretrial.json: every hypothesis needs an id and text")
    crit = p.get("criteria", [])
    if not isinstance(crit, list) or not 2 <= len(crit) <= 4:
        bad.append("pretrial.json: criteria must be a list of 2 to 4")
    else:
        for c in crit:
            if not isinstance(c, dict) or not c.get("id") or not c.get("name"):
                bad.append("pretrial.json: every criterion needs an id and a name")
            elif c.get("weight") not in (1, 2, 3):
                bad.append(f"pretrial.json: criterion {c.get('id')} weight must be 1, 2 or 3")
    seats = p.get("seats", [])
    if not isinstance(seats, list) or not 3 <= len(seats) <= 8:
        bad.append("pretrial.json: seats must be a list of 3 to 8")
    else:
        names = [str(s.get("seat", "")).strip() for s in seats if isinstance(s, dict)]
        if len(names) != len(seats) or not all(names):
            bad.append("pretrial.json: every seat needs a name")
        if len({seat_file(n) for n in names}) != len(names):
            bad.append("pretrial.json: two seats share a name")
        if sum(1 for s in seats if isinstance(s, dict) and s.get("premortem") is True) != 1:
            bad.append("pretrial.json: exactly one seat must have \"premortem\": true")
        if any(isinstance(s, dict) and not str(s.get("question", "")).strip() for s in seats):
            bad.append("pretrial.json: every seat needs its own question")
        if setup and setup.get("seats"):
            want = sorted(s["seat"].lower() for s in setup["seats"])
            if sorted(n.lower() for n in names) != want:
                bad.append(f"pretrial.json: seats must be exactly the ones the user chose: {want}")
        elif setup and len(seats) != setup.get("jurors"):
            bad.append(f"pretrial.json: the user asked for {setup.get('jurors')} seats, got {len(seats)}")
    if bad:
        raise CaseError(bad)
    return p

def build_record(case, seed=None):
    p = check_pretrial(case)
    bad, speeches = [], {}
    for name, cap in CAPS.items():
        path = os.path.join(case, name)
        if not os.path.exists(path):
            if name.startswith("opening"):
                bad.append(f"{name}: missing")
            continue
        text = read(path).strip()
        n = words(text)
        if n > cap * SLACK:
            bad.append(f"{name}: {n} words, the limit is {cap}; ask that side to cut it")
        speeches[name] = (text, n)
    if ("rebuttal-for.md" in speeches) != ("rebuttal-against.md" in speeches):
        bad.append("rebuttals: one side filed a rebuttal and the other did not")
    if bad:
        raise CaseError(bad)

    rng = random.Random(seed)
    order = ["for", "against"]
    rng.shuffle(order)  # who speaks first in the record is random, so neither side owns the first word
    title = {"for": "For the motion", "against": "Against the motion"}
    out = [f"# The record\n\n**Motion.** {p['motion']}\n",
           f"**Standard of proof.** {p['standard'].replace('_', ' ')}. The burden is on the side for the motion.\n",
           "## Hypotheses the judge set before any argument\n"]
    out += [f"- **{h['id']}** {h['text']}" for h in p["hypotheses"]]
    out.append("\n## Criteria\n")
    out += [f"- **{c['id']}** {c['name']} (weight {c['weight']}): {c.get('question', '')}" for c in p["criteria"]]
    out.append("\n## The case file\n")
    out.append(read(os.path.join(case, "case.md")).strip() if os.path.exists(os.path.join(case, "case.md"))
               else "_No case file._")
    for stage in ("opening", "rebuttal"):
        if f"{stage}-for.md" not in speeches:
            continue
        out.append(f"\n## {stage.capitalize()}s\n")
        for side in order:
            text, n = speeches[f"{stage}-{side}.md"]
            out.append(f"### {title[side]} ({n} words)\n\n{text}\n")
    out.append(f"\n_Order of sides in this record: {', '.join(title[s] for s in order)} (random)._\n")
    write(os.path.join(case, "record.md"), "\n".join(out))
    return order

def check_ballot(b, seat, criteria, rnd, path):
    tag = os.path.relpath(path)
    bad = []
    if not isinstance(b, dict):
        return [f"{tag}: a ballot must be a JSON object"]
    if str(b.get("seat", "")).strip().lower() != seat.lower():
        bad.append(f"{tag}: seat is {b.get('seat')!r}, expected {seat!r}")
    if b.get("verdict") not in VERDICTS:
        bad.append(f"{tag}: verdict must be one of {VERDICTS}")
    prob = b.get("probability")
    if not isinstance(prob, (int, float)) or isinstance(prob, bool) or not 0 <= prob <= 100:
        bad.append(f"{tag}: probability must be a number from 0 to 100")
    if b.get("confidence") not in CONFIDENCE:
        bad.append(f"{tag}: confidence must be low, medium or high")
    findings = b.get("findings")
    if not isinstance(findings, list) or not 1 <= len(findings) <= 6:
        bad.append(f"{tag}: findings must be a list of 1 to 6")
    else:
        for i, f in enumerate(findings, 1):
            if not isinstance(f, dict) or not str(f.get("text", "")).strip():
                bad.append(f"{tag}: finding {i} needs text")
                continue
            if f.get("grade") not in GRADES:
                bad.append(f"{tag}: finding {i} grade must be verified, plausible or assumption")
            if f.get("favors") not in FAVORS:
                bad.append(f"{tag}: finding {i} favors must be for, against or neither")
            if not re.fullmatch(r"([FA]\d+|case)", str(f.get("claim", ""))):
                bad.append(f"{tag}: finding {i} claim must be a claim id like F2 or A1, or \"case\"")
    scores = b.get("scores")
    if not isinstance(scores, dict) or set(scores) != set(criteria):
        bad.append(f"{tag}: scores must give every criterion exactly once: {sorted(criteria)}")
    elif any(not isinstance(v, int) or isinstance(v, bool) or not 1 <= v <= 5 for v in scores.values()):
        bad.append(f"{tag}: every score must be a whole number from 1 to 5")
    for key in ("decisive", "change_my_mind"):
        if not str(b.get(key, "")).strip():
            bad.append(f"{tag}: {key} is empty")
    if b.get("verdict") == "adopt_with_conditions" and not b.get("conditions"):
        bad.append(f"{tag}: adopt_with_conditions needs at least one condition")
    if rnd == 2 and "flip_reason" not in b:
        bad.append(f"{tag}: round 2 ballots need flip_reason (empty string if nothing changed)")
    return bad


def load_round(case, seats, criteria, rnd):
    folder = os.path.join(case, "ballots", f"round{rnd}")
    ballots, bad = {}, []
    for s in seats:
        path = os.path.join(folder, seat_file(s))
        try:
            b = load_json(path)
        except CaseError as e:
            bad += [f"ballots/round{rnd}/{m}" for m in e.problems]
            continue
        bad += check_ballot(b, s, criteria, rnd, path)
        ballots[s] = b
    if bad:
        raise CaseError(bad)
    return ballots


# ---------- tally ----------

def majority_side(ballots):
    counts = {"for": 0, "against": 0, "neither": 0}
    for b in ballots.values():
        counts[SIDE[b["verdict"]]] += 1
    top = max(counts.values())
    leaders = [s for s, n in counts.items() if n == top]
    return (leaders[0] if len(leaders) == 1 else "tied"), counts


def audit_flips(r1, r2):
    """Round 2 is trusted only if the jurors who moved say what new point moved them."""
    side1, _ = majority_side(r1)
    flips = []
    for seat, b2 in r2.items():
        b1 = r1[seat]
        moved = b1["verdict"] != b2["verdict"] or abs(b1["probability"] - b2["probability"]) > MOVE
        if not moved:
            continue
        cited_before = {f["claim"] for f in b1["findings"]}
        reason = str(b2.get("flip_reason", "")).strip()
        new_point = bool(re.search(r"\bJuror [A-H]\b", reason)) or any(
            c not in cited_before for c in re.findall(r"\b[FA]\d+\b", reason))
        toward = SIDE[b2["verdict"]] == side1 and SIDE[b1["verdict"]] != side1
        flips.append({"seat": seat, "from": b1["verdict"], "to": b2["verdict"],
                      "probability": [b1["probability"], b2["probability"]],
                      "justified": bool(reason) and new_point, "toward_majority": toward, "reason": reason})
    unjustified = sum(1 for f in flips if not f["justified"])
    herding = bool(flips) and all(f["toward_majority"] for f in flips) and not any(f["justified"] for f in flips)
    if flips and (unjustified * 2 > len(flips) or herding):
        return flips, 1, (f"{unjustified} of {len(flips)} changes named no new point"
                          + ("; every change moved toward the round 1 majority" if herding else ""))
    return flips, 2, "round 2 changes cite new points" if flips else "nobody changed their vote"


def summarize(ballots, criteria):
    probs = sorted(b["probability"] for b in ballots.values())
    weights = [CONFIDENCE[b["confidence"]] for b in ballots.values()]
    side, counts = majority_side(ballots)
    n = len(ballots)
    top = max(counts["for"], counts["against"], counts["neither"])
    spread = "unanimous" if top == n else ("lean" if top * 3 >= n * 2 else "split")
    q = statistics.quantiles(probs, n=4, method="inclusive") if n >= 2 else [probs[0]] * 3
    crit_means = {c: round(statistics.mean(b["scores"][c] for b in ballots.values()), 2) for c in criteria}
    verified = {"for": 0, "against": 0, "neither": 0}
    for b in ballots.values():
        for f in b["findings"]:
            if f["grade"] == "verified":
                verified[f["favors"]] += 1
    minority = []
    for seat, b in ballots.items():
        if side in ("for", "against") and SIDE[b["verdict"]] != side:
            against_majority = [f for f in b["findings"] if f["grade"] == "verified" and f["favors"] not in (side, "neither")]
            minority.append({"seat": seat, "verdict": b["verdict"], "probability": b["probability"],
                             "decisive": b["decisive"], "verified_against_majority": len(against_majority)})
    return {
        "jurors": n,
        "verdicts": {v: sum(1 for b in ballots.values() if b["verdict"] == v) for v in VERDICTS},
        "sides": counts, "majority_side": side, "spread": spread,
        "probability": {"median": statistics.median(probs), "q1": q[0], "q3": q[2], "min": probs[0], "max": probs[-1],
                        "confidence_weighted_mean": round(sum(p * w for p, w in zip(
                            [b["probability"] for b in ballots.values()], weights)) / sum(weights), 1)},
        "criteria_means": crit_means,
        "verified_findings": verified,
        "minority": minority,
        "strong_minority": any(m["verified_against_majority"] for m in minority),
        "objections": [{"seat": s, "objection": b["objection"]} for s, b in ballots.items() if b.get("objection")],
    }


def tally(case, seed=None):
    p = check_pretrial(case)
    seats = [s["seat"] for s in p["seats"]]
    criteria = [c["id"] for c in p["criteria"]]
    r1 = load_round(case, seats, criteria, 1)
    used, rounds, flips, note = r1, 1, [], "blind vote only"
    if os.path.isdir(os.path.join(case, "ballots", "round2")):
        r2 = load_round(case, seats, criteria, 2)
        flips, rounds, note = audit_flips(r1, r2)
        used = r2 if rounds == 2 else r1
    result = summarize(used, criteria)
    setup = load_setup(case)
    juror_models = {seat: seat_model(setup, seat) for seat in seats}
    distinct = sorted(set(juror_models.values()))
    result.update({
        "round_used": rounds, "round_note": note, "flips": flips, "juror_models": juror_models,
        "correlation_note": (f"Every juror ran on the same model ({distinct[0]}), so their errors are likely "
                             "correlated; agreement is weaker evidence than the count suggests.")
                            if len(distinct) == 1 else
                            (f"Jurors ran on {len(distinct)} models ({', '.join(distinct)}), all from one family; "
                             "that spreads the errors a little, not fully."),
    })

    rng = random.Random(seed)
    order = list(used)
    rng.shuffle(order)  # the judge reads ballots in a random order under letters, never in seating order
    letters = {seat: f"Juror {chr(65 + i)}" for i, seat in enumerate(order)}
    result["packet_order"] = [letters[s] for s in order]
    write(os.path.join(case, "tally.json"), json.dumps(result, indent=2) + "\n")

    lines = [f"# Jury packet\n\nBallots from round {rounds} ({note}), in random order. "
             "Each juror voted alone before seeing any other ballot.\n"]
    for seat in order:
        b = used[seat]
        lines.append(f"## {letters[seat]}: {seat}\n")
        lines.append(f"**Verdict** {LABELS[b['verdict']]} · **probability** {b['probability']} · "
                     f"**confidence** {b['confidence']}\n")
        lines.append("**Findings**")
        lines += [f"- [{f['claim']}, {f['grade']}, favors {f['favors']}] {f['text']}" for f in b["findings"]]
        lines.append(f"\n**Scores** " + ", ".join(f"{k} {v}" for k, v in b["scores"].items()))
        lines.append(f"\n**Decisive** {b['decisive']}\n\n**Would change my mind** {b['change_my_mind']}")
        if b.get("conditions"):
            lines.append("\n**Conditions**")
            lines += [f"- {c}" for c in b["conditions"]]
        if b.get("objection"):
            lines.append(f"\n**Objection to the motion** {b['objection']}")
        if rounds == 2 and b.get("flip_reason"):
            lines.append(f"\n**Why I moved** {b['flip_reason']}")
        lines.append("")
    write(os.path.join(case, "jury-packet.md"), "\n".join(lines))
    return result, letters

def check_ruling(case):
    path = os.path.join(case, "ruling.md")
    if not os.path.exists(path):
        raise CaseError("ruling.md: missing")
    text = read(path)
    bad = []
    first = text.strip().splitlines()[0] if text.strip() else ""
    m = re.fullmatch(r"VERDICT: (Adopt|Adopt with conditions|Redesign|Reject|Insufficient evidence) "
                     r"\(confidence (low|medium|high)\)", first.strip())
    if not m:
        bad.append("ruling.md: first line must read 'VERDICT: <Adopt | Adopt with conditions | Redesign | Reject | "
                   "Insufficient evidence> (confidence <low|medium|high>)'")
    bad += [f"ruling.md: missing section '{s}'" for s in RULING_SECTIONS if s not in text]
    if words(text) > 600 * SLACK:
        bad.append(f"ruling.md: {words(text)} words, the limit is 600")
    if bad:
        raise CaseError(bad)
    return m.group(1), m.group(2)


def close(case):
    verdict, conf = check_ruling(case)
    motion = check_pretrial(case)["motion"]
    docket = os.path.join(os.path.dirname(os.path.abspath(case)), "docket.md")
    line = f"- {os.path.basename(os.path.abspath(case))} · {verdict} ({conf}) · {motion}\n"
    existing = read(docket) if os.path.exists(docket) else "# Docket\n\n"
    if line not in existing:
        write(docket, existing + line)
    return verdict, conf


def list_cases(base):
    if not os.path.isdir(base):
        return []
    rows = []
    for name in sorted(os.listdir(base)):
        case = os.path.join(base, name)
        if not os.path.isdir(case):
            continue
        try:
            verdict = check_ruling(case)[0]
        except CaseError:
            verdict = "open"
        try:
            motion = load_json(os.path.join(case, "pretrial.json")).get("motion", "")
        except CaseError:
            motion = ""
        rows.append((name, verdict, motion))
    return rows
